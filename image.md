# Portfolio Image Set — Cybersecurity Portfolio

## Image Selection Approach

For my portfolio, I separated images into two categories: real captures that prove my work and generated visuals that support the presentation.

The main rule I followed was that anything representing my actual development work should be real. AI-generated images were only used where the purpose was visual communication rather than evidence.

---

# Real Images Used

## 1. J.A.R.V.I.S. Cybersecurity Platform Screenshots

**Decision: Real screenshots**

I used screenshots captured directly from my J.A.R.V.I.S. cybersecurity platform.

Purpose:

* Show the actual interface I developed
* Demonstrate dashboard design and security workflow concepts
* Provide evidence of the completed project

Why I chose real images:
A generated cybersecurity dashboard could look impressive but would not prove that I created the system. The real screenshots show my actual implementation, design choices, and development progress.

---

## 2. AI Portfolio Terminal Screenshots

**Decision: Real screenshots**

I used real captures from my AI Portfolio Terminal project.

Purpose:

* Show frontend engineering ability
* Demonstrate AI and data-focused development
* Present another technical project outside cybersecurity

Why I chose real images:
The screenshot represents real functionality and gives viewers confidence that the project exists.

---

## 3. Pink Panther Project Screenshots

**Decision: Real screenshots**

I used real captures from my frontend design project.

Purpose:

* Show UI/UX skills
* Demonstrate visual design ability
* Balance the technical focus of the portfolio

Why I chose real images:
The project is about design quality, so the actual interface is the strongest proof.

---

# AI-Generated Image Used

## 4. Architecture Diagram / System Visualization

**Decision: AI-generated supporting visual**

I used an AI-generated architecture-style image to communicate the idea of a technical system structure.

Purpose:

* Improve visual storytelling
* Make the architecture section easier to understand
* Add a consistent futuristic cybersecurity feeling

Why I chose AI for this:
The image was not used as proof of an existing product. It was used as a supporting visual to explain concepts and create a stronger presentation.

---

# Rejected Image

## AI-generated Cybersecurity Dashboard

I rejected an AI-generated SOC dashboard image because it looked like a real product screenshot but did not represent something I built.

Although it had a professional appearance, using it would create confusion between fictional visuals and actual project evidence.

I replaced it with my real project screenshots because authenticity was more important than visual perfection.

---

# Final Decision

My final image set uses real captures for all project evidence and AI-generated visuals only for supporting presentation elements.

The portfolio prioritizes:

* authenticity,
* technical proof,
* consistent visual style,
* and clear communication of my engineering work.
