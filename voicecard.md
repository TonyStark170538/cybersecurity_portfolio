Portfolio Case Studies
1. AI Portfolio Terminal
Problem

I wanted to explore how artificial intelligence could make financial information easier to understand. Many financial tools present large amounts of data but require users to manually connect the pieces before making decisions. My goal was to build a product that combines data visualization, AI workflows, and software engineering into one experience.

What I Did & Decisions

I designed the project as a React and TypeScript application with a modular architecture so new AI features could be added without changing the overall structure. I separated the frontend from future backend services and focused on reusable components rather than one-off implementations. Throughout development I prioritized clean architecture, readability, and maintainability over adding unnecessary complexity.

Outcome

The project strengthened my understanding of React architecture, TypeScript, component design, and integrating AI concepts into real software. It also became a strong portfolio project demonstrating how I approach product development instead of isolated technical experiments.

2. J.A.R.V.I.S. Cybersecurity Platform
Problem

Security analysts often have to work with multiple disconnected tools for monitoring, threat intelligence, and incident response. I wanted to design a dashboard that demonstrates how these workflows could be unified into a single interface.

What I Did & Decisions

I built a Security Operations Center-inspired dashboard using React and TypeScript. Instead of trying to imitate an existing SIEM, I focused on designing reusable components that could later integrate with real security telemetry, Wazuh, MITRE ATT&CK mappings, and automation features. I organized the interface around security workflows rather than individual pages because I wanted usability to reflect how analysts actually work.

Outcome

The project helped me better understand security operations, dashboard architecture, and designing software around user workflows. It also gave me experience thinking beyond code by considering how security professionals interact with information during investigations.

3. Pink Panther
Problem

Many websites function correctly but lack personality or a consistent design system. I wanted to build a frontend project that balanced visual design with clean engineering practices.

What I Did & Decisions

I developed a responsive React application using Tailwind CSS with reusable UI components and consistent spacing, typography, and branding. Rather than focusing only on appearance, I organized the project around reusable patterns that make future maintenance easier.

Outcome

The project improved my frontend development skills while teaching me the importance of consistency, user experience, and component-based design. It also demonstrated that good software is not only functional but also enjoyable to use.
